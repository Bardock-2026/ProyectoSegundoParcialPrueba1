Implementadas clases CRUD y menú interactivo en consola

Se añadieron clases CRUD para Cliente, Habitación, Reserva y Pago, con métodos para todas las operaciones básicas. 
El menú principal fue reemplazado por un menú interactivo en consola. 
Se mejoró la validación y el constructor en Pago, y se agregaron métodos auxiliares para obtener entidades por ID. 
Al crear o eliminar reservas, se actualiza el estado de la habitación. 
Se incluyeron mensajes y validaciones para mejorar la experiencia de usuario.
